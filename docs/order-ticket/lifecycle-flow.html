Full lifecycle flow

Quote-until-payment lifecycle: customer confirm alone does not create an order; payment (or net terms / admin override) converts QUO-* → ORD-*; production release sets in_production and marks the linked lead Won.

Code: maybe-convert-quote-to-order.ts · maybe-auto-release-production.ts · public /q/{token}

  START([Rep sends quote]) --> SENT["Quote Sent · sent · QUO-* · /quotes"]

  SENT --> CONFREQ{Require client confirmation?}

  CONFREQ -->|No| PRICEOK["Price gate open · Not required"]
  CONFREQ -->|Yes| CONFWAIT["/q/token · Confirm quote price"]

  CONFWAIT --> CONFCLICK{Customer confirmed?}

  PAYFULL --> PAYMETHOD
  PAYDEP --> PAYMETHOD

  PAYMETHOD{Channel?}

  PAYMETHOD -->|Cash + receipt| CASH[Payment recorded]
  PAYMETHOD -->|Wire / ACH / Zelle / card| EVID[Evidence uploaded · not paid yet]

  EVID --> EVIDPEND["Awaiting confirmation · /payments + /orders"]
  EVIDPEND --> ACCT{Accountant confirms?}
  ACCT -->|No| EVIDPEND
  ACCT -->|Yes| PAIDRECORD[Payment recorded · email sent]

  CASH --> GATES
  PAIDRECORD --> GATES

  GATES{Convert gates met?}

  GATES -->|No| SENT
  GATES -->|Yes| ORDER["ORDER · ORD-* · /orders"]

  NETCONV --> PRODCHK

  ORDER --> PRODCHK{Production gates met?}

  PRODCHK -->|Partial · balance due| ORDERPART[Pending payment · deposit paid]

3 CRM pages at each stage

Where staff and customers see the ticket at each lifecycle step.

Stage Ticket status Ref CRM page Public page
Quote draft draft QUO-* /quotes —
Quote sent sent QUO-* /quotes /q/{token} — confirm + pay
Confirmed, awaiting pay sent + client_confirmed QUO-* /quotes · Confirmed — awaiting deposit /q/{token}
Payment under review sent or order + evidence QUO-* or ORD-* /payments + /orders · Awaiting payment confirmation /q/{token} — under review
Order order ORD-* /orders · Pending Payment /q/{token}
In production in_production ORD-* /orders · In Production /q/{token} — pay balance if partial
Completed completed ORD-* /completed /q/{token} — ready for pickup

4 What does not convert to order

Actions that alone do not move the ticket to order status.

Action alone Converts to order?
Customer confirms on public link No — sets client_confirmed only; stays on /quotes
Customer uploads wire/ACH evidence No — queues for accountant; stays quote until payment recorded
SDR/Sales Convert to Order No — button hidden; admin only
Net terms + customer confirm (gates pass) Yes — may convert + auto-release on confirm
Accountant record_payment / cash auto-record Yes — when payment + confirm gates pass
Admin manual convert Admin — override; Admin converted banner if confirm/payment missing

5 Lead Won timing

Won is credit for production release — not order conversion.

flowchart LR
  A[Order conversion] --> B{Production released?}
  B -->|No| C["Lead NOT Won · Quote Sent / Ongoing"]
  B -->|Yes · in_production| D["Lead sales_status = Won"]
✓
Won is not set when the ticket becomes order. It is set only when production_released_at is set (markLeadWonOnProduction).
