Needs answer Q10b — Canvas Prints, Jars, and Tubes

These were in the prototype but are not in the production system as product types. In the production system, Jars and Tubes are listed as "application containers" — labels are applied to them, so the product being printed is actually the label.

Notes
Needs answer Q10c — Should the quote builder know which facility a job runs at?

The production system splits jobs between 16th Street (labels, pouches, boxes) and Boyd Street (vinyl, banners, large format). The facility determines which materials are available. For example: Diecut Stickers at 16th Street use BOPP material, but at Boyd Street they use Vinyl.

Notes
Needs answer Q10d — How much material detail should reps see?

Cardstock alone has 9 specific options: 14pt C1S, 14pt C2S, 16pt C1S, 16pt C2S, 18pt C1S, 18pt C2S, 18pt Silver, 24pt C1S, 24pt C2S. Should Sales reps pick the exact weight and finish when quoting, or is "Cardstock" enough and production selects the weight?

Pricing Calculator
3 decisions needed ▾
Needs answer Q17 — Should the pricing calculator be built into the quote builder?

There is a separate pricing calculator that helps reps figure out what to charge a customer. It takes the item size and quantity, calculates how many pieces fit on a press frame, and looks up the cost per frame from a tier price table. The output is a suggested price per piece.

Right now the rep opens this calculator separately, gets the price, then types it into the quote manually.

Notes
Needs answer Q18a — When admin adds a new product, should they also set up its pricing?

Each product type uses a specific press machine and tier price table to calculate production cost. If the admin can add new product types, they need a way to configure the pricing rules for that product — otherwise the calculator will not know what to charge for it.

Notes
Needs answer Q18b — Should the pricing tier rates be editable from the admin panel?

The tier rates are numbers like "Labels: 500+ frames = $3.40 per frame". If these change (e.g. press costs go up), should the owner be able to update them from the admin panel without calling a developer?

Notes
